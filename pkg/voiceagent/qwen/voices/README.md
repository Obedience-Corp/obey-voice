# Embedded Veronica reference audio

`veronica/ref.wav` and `veronicadesk/ref.wav` were **Created with Grok**
(Imagine). Adjacent `meta.json` files identify the source clip names and reference
phrases. On 2026-11-04 the owner confirmed both clips were entirely generated
in their Imagine account, without real-person input.

Offline ASR matches the documented phrases. This is not human listening or
speaker-identity verification. The two synthetic references remain pending the
specific provider output-permission question documented in
[review evidence](../../../../docs/media-review-evidence.md#veronica-reference-clips).
Attribution alone is not recorded as a redistribution or cloning permission grant.
No source video or model weights are bundled in this directory.
