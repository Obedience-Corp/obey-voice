# Original recording replay and explicit transcript retry

Recorded input rows now expose **Replay original** and **Transcribe recording** in the desktop. The terminal offers `/input` to list recordings, `/input replay N` and `/input transcribe N`. Pause microphone input and let the current turn finish first. Interrupt stops an active review; review owns the ordinary tracked foreground slot, so capture, another review, Clear and manager changes cannot overlap it.

Replay resolves the original session-owned WAV by utterance ID and capture epoch, verifies its admitted sample geometry and plays its PCM at 16 kHz. It neither calls a model nor regenerates missing audio. An explicit replay can open the selected playback device even in an otherwise silent conversation; unattended verification injects a software engine instead. No WAV bytes or base64 cross the UI bridge. Availability comes from retained session ownership, including verified restoration, and unavailable originals are labeled rather than reconstructed.

Transcribe recording is an explicit retry through the current Native persona's same-model transcription route. It works when automatic transcription is off, without changing that policy. Standard cannot silently choose another recognizer. The operation cancels/joins optional captions, retains the input until its request finishes and uses the current binding's publication lease. Cancellation, expired leases and stale recording identities cannot publish a transcript. A successful retry changes the original canonical row and saves it, without adding a new user turn. It can repair the missing-transcript barrier before an explicit Native→Standard switch.

Focused race tests cover exact original samples, wrong ID/epoch, missing originals, replay cancellation/join, ownership release, explicit retry with automatic captions off, canceled HTTP bodies and refused publication leases. Product restore tests prove a missing-transcript Standard switch preserves Native, explicit retry runs exactly once, then Standard projection succeeds and saves the actual transcript.
